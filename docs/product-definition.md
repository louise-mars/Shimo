# 拾墨 (Shimo) — 产品定义文档

> 版本：v1.0 | 日期：2026年5月 | 状态：v1.0 已完成

---

## 一、产品定位

### 一句话定义
**拾墨不是笔记软件，而是"思维捕捉-回流系统"（Thinking Capture & Reflow System）**

### 核心品牌气质
克制 / 留白 / 片段 / 思考 / 轻结构

**品牌主张：在碎片中，建立秩序**

### 与竞品的本质区别

| 产品 | 本质 |
|------|------|
| Apple Notes | 记录工具 |
| Notion | 结构系统 |
| **拾墨** | **思维流系统** |

---

## 二、核心用户

**当前阶段：** 开发者本人（单用户私人工具），中文环境，碎片化记录为主。

**目标用户画像（未来）：**
- 有持续思考习惯的知识工作者
- 需要随时捕捉灵感的创作者
- 希望笔记"有用"而不只是"存档"的人

---

## 三、核心用户场景（5个）

### 场景1：灵光一闪 → 3秒落笔
走在路上突然有个想法，掏出手机，不需要想"存哪里"，直接说或写，自动保存。

- **关键体验：** 打开即写，零摩擦
- **触发方式：** Widget 长按语音 / 打开 App 点 +

### 场景2：沉浸写作 → 忘记时间
坐下来写日记或长文，界面安静，傍晚/夜晚有落花飘过，不被打扰。

- **关键体验：** 时间感知氛围（晨/昼/暮/夜），停止输入2.5秒自动进入沉浸模式

### 场景3：会议/工作记录 → 清晰不费脑
开会时快速记要点，语音说完自动整理成结构化笔记。

- **关键体验：** 语音 → AI 自动分句、打标签、提取标题

### 场景4：找回旧记忆 → 5秒内找到
想起上周记了什么，搜一下就出来，或者问 AI。

- **关键体验：** 全文搜索 + AI 问答（基于自己的笔记）

### 场景5：睡前回顾 → 今天的我
睡前收到推送，看看今天记了什么，可快速追加。

- **关键体验：** 每晚9点本地推送，AI 生成今日摘要

## 四、思维流路径（核心闭环）

```
想到（Trigger）
    ↓
语音/文字捕捉（Capture）
    ↓
AI 转文本 + 轻结构化（Structure）
    ↓
存入时间流（Memory）
    ↓
回看 / 搜索 / 问 AI（Retrieve）
    ↓
再次激发新想法（Reflow）  ← 这是隐藏价值点
    ↓
回到"想到"
```

**关键原则：这是循环，不是线性流程**

---

## 五、设计原则

1. **氛围优先** — 每个场景有独立的视觉情绪
2. **零摩擦入口** — 打开即写，标题/分类可以不填
3. **语音是输入层** — 与键盘平级，不是独立功能
4. **不改变用户表达，只稍微整理** — AI 的边界：分句、打标签、提取标题
5. **克制功能** — 不做文件夹树、Block 系统、AI 写作
6. **静默保存** — 无保存按钮，无确认弹窗

## 六、产品结构

```
拾墨
├── 输入层（Input Layer）
│   ├── 键盘输入（主）
│   ├── 语音输入（辅，底部语音栏）
│   └── Widget 快捷入口（桌面/锁屏）
│
├── 存储层（Notes Layer）
│   └── 时间流（今天/昨天/本周/月份）
│
├── 结构层（Light Structure）
│   ├── #标签（自动识别 + AI 建议）
│   └── 日程识别（→ 知天日历）
│
└── 回流层（Reflow Layer）
    ├── 搜索（全文 + 标签）
    ├── 问 AI（基于自己的笔记）
    └── 今日回顾推送（每晚9点）
```

## 七、与知天的关系

**互补工具，不合并**

| | 拾墨 | 知天 |
|--|------|------|
| 核心 | 思维 | 时间 |
| 内容 | 想法、灵感、记录 | 天气、日程、提醒 |

**数据通道：**
- 拾墨 → 知天：识别笔记中的日期时间，写入系统日历
- 知天 → 拾墨：时间感知（傍晚/夜晚触发落花氛围）

---

## 八、AI 定位

**不做通用 AI，做专属于你笔记的 AI**

| 功能 | 说明 |
|------|------|
| 语音转结构化 | 说完话 → 自动分句、打标签、提取标题 |
| 自动打标签 | 写完后 AI 建议标签 |
| 问我的笔记 | 用自然语言查询自己的笔记内容 |
| 今日摘要 | 每晚推送时附带 AI 生成的今日总结 |

**支持的 AI 提供商（按优先级）：**
- MiniMax（中文能力强，价格低）
- Kimi / 月之暗面（长文本理解强，128K 上下文）
- 智谱 GLM（清华系大模型，GLM-4 Flash 免费）
- 通义千问（阿里大模型，中文优秀）
- OpenRouter（聚合平台，可切换 DeepSeek/GPT 等）
