# 拾墨设计系统

> 唯一真相源：`Shared/src/styles/tokens.css`

## 间距

基数：8px

| Token | 值 | 用途 |
|-------|-----|------|
| --space-1 | 4px | 图标间距、标签内边距 |
| --space-2 | 8px | 按钮间距、列表项间距 |
| --space-3 | 12px | 卡片内边距、区块间距 |
| --space-4 | 16px | 页面边距、区域间距 |
| --space-5 | 20px | 页面顶部边距 |
| --space-6 | 24px | 弹窗内边距 |
| --space-8 | 32px | 大区块间距 |

## 字体阶梯

| Token | 值 | 用途 |
|-------|-----|------|
| --text-xs | 10px | 标签、辅助信息、section 标题 |
| --text-sm | 12px | 时间、计数、状态文字 |
| --text-base | 14px | 正文、按钮、列表项 |
| --text-lg | 16px | 编辑器正文 |
| --text-xl | 20px | Logo |
| --text-2xl | 24px | 编辑器标题 |

## 字体族

| 用途 | 字体 |
|------|------|
| 标题/内容 | Noto Serif SC（书写感） |
| 界面文字 | Noto Sans SC（可读性） |
| 数字/英文 | Inter（精准） |
| 代码 | JetBrains Mono |

## 颜色语义

| 语义 | 变量 | 用途 |
|------|------|------|
| 品牌/操作 | --accent (#B5341A) | 新建按钮、收藏激活、链接 |
| 正向反馈 | --success (#4A7C6F) | 已保存、已同步 |
| 破坏性操作 | --danger (#B5341A) | 删除按钮、错误提示 |
| 辅助信息 | --text-faint | 时间、计数、占位符 |

## 组件规范

| 规范 | 值 |
|------|-----|
| 按钮最小触控区域 | 44×44px |
| 圆角 | 6-8px（克制，不过度圆润） |
| 过渡时长 | 160ms |
| 行距 | 1.6-1.9 |
| 编辑器最大宽度 | 680px |
| 侧边栏宽度 | 180-260px |

## 状态反馈

| 状态 | 颜色 | 图标 |
|------|------|------|
| 编辑中 | --text-faint | ● |
| 保存中 | --accent | ● (pulse) |
| 已保存 | --success | ✓ |
| 同步中 | --accent | ● (pulse) |
| 已同步 | --success | ● |
| 同步失败 | --danger | ● |
